웹사이트 사용 및 발표 가이드

1. 주요 기능

• 엑셀 파일 직접 업로드: 통계청 가계동향조사 서식의 엑셀 파일(.xlsx)을 업로드하면 브라우저에서 즉시 데이터를 읽고 계산합니다.

• 자동 전년동기대비(YoY) 계산: 2019년 Q1부터의 데이터를 바탕으로 2020년 Q1~2026년 Q2(26개 분기)의 변화율(%)을 수식 ((현재분기 - 전년동기)/전년동기)*100에 맞춰 자동 계산합니다.

• 자동 시각화 및 양극화 분석: 소득/소비 증가율, 1분위 vs 5분위 격차(pp), 평균 상회 분기 수를 실시간 그래프와 표로 표현합니다.

• 팩트 기반 자동 종합 분석: 정량적 데이터 결과만을 바탕으로 객관적 사실과 해석을 명확히 구분한 발표용 요약문을 자동 출력합니다.

2. 발표 시연 가이드

• 발표 화면 상단에서 샘플 데이터 로드를 클릭하면 기본 통계 데이터셋으로 즉시 시연할 수 있습니다.

• 새로운 엑셀 파일 업로드 시, 기존 수치 및 시각화, 자동 보고서 문장이 새 데이터에 맞게 100% 자동 재계산됩니다.
